# Paper — демо-счёт по сигналам

Виртуальный счёт **$1000**, который торгует сигналы с доски [Signals](https://petraballas.github.io/signals-board/).
Деньги ненастоящие. Бот **не подключён ни к какой бирже** и не использует ключи API — только публичные свечи (Bybit → OKX → Gate).

- `core.js` — движок сигналов, тот же файл, что на доске Signals.
- `bot.js` — симуляция: вход, стоп, TP1 (50% + стоп в безубыток), TP2, ликвидация (изолированная, плечо 5–50x выбирается под сделку; старые позиции — 20x), комиссия 0,055%/сторона, фондинг не учитывается.
- Состояние пишется в ветку `data` → `state.json`. Сайт (GitHub Pages, ветка `main`) читает его.
- Запуск каждые 5 минут через GitHub Actions: `setup/paper.yml` нужно положить в `.github/workflows/paper.yml` (для этого нужен токен со scope `workflow`).

Правила: сигналы от 4★ (пробой, отскок, откат, SMC); риск 4★ 2% / 5★ 3% (×0,5 после 3 убытков подряд или просадки >10%, максимум 3%); плечо — минимальное из 5/10/20/25/50x, при котором маржа ≤ 9% эквити и ликвидация ≥ 1,5× стопа, иначе пропуск, максимум 10 сделок, одна позиция на монету.
Не является финансовой рекомендацией.
